# AI-Powered Student Performance Analysis System

## Project Overview

The AI-Powered Student Performance Analysis System is a Python-based web application developed to analyze student academic performance through an interactive dashboard.

It uses data analysis, data visualization, machine learning, and AI integration to provide insights into student performance.

## Features

* Add and manage student records
* Calculate average marks and attendance
* Categorize student performance
* Search and filter student records
* Visualize subject-wise marks
* Analyze study hours and attendance
* Predict student performance using machine learning
* Generate AI-powered study guidance using Gemini

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Gemini API

## How to Run the Project

### 1. Install Python

Install Python on your computer if it is not already installed.

### 2. Install Dependencies

Open the terminal in the project folder and run:

```bash
pip install -r requirements.txt
```

### 3. Configure the Gemini API Key

If you want to use the AI study guidance feature, create a `.streamlit/secrets.toml` file locally and add your Gemini API key.

Never upload this file or your API key to GitHub.

### 4. Run the Application

Run the following command:

```bash
streamlit run app.py
```

## Project Objective

The objective is to demonstrate the application of Python, data science, data visualization, machine learning, and generative AI in student performance analysis.
